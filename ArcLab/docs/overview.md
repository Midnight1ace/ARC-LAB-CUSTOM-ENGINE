# ArcLab Overview

ArcLab is being built around experiments rather than game levels. The first proof is a narrow but complete scientific loop:

1. Configure a magnetic particle experiment.
2. Run a deterministic fixed-step simulation.
3. Visualize particles, fields, and trails.
4. Record sensor data.
5. Export results.

The current codebase implements the simulation/data foundation as a console prototype. Renderer and editor work comes next.
