# Roadmap

## M0: Engine Boots

- CMake project builds.
- Executable starts and logs startup.
- Console simulation runs and exits cleanly.

## M1: Simulation Core

- Vector math.
- Fixed timestep loop.
- Particle emitter.
- Electric and magnetic fields.
- Lorentz force.
- CSV sensor export.

## M2: Viewport Prototype

- Window.
- Camera.
- Grid.
- Debug lines.
- Particle rendering.
- Trail rendering.

## M3: Editor Shell

- Scene explorer.
- Properties panel.
- Simulation controls.
- Graph panel.
- Console/profiler panels.
